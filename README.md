# OBJECT_RECOGNITION_SYSTEM_Infosys_Internship_Oct2024
The goal of this project is to create an intelligent system that can detect and recognize different objects in real time using a webcam or static images. It’s based on some of the most powerful computer vision models such as YOLOv5, YOLOv8, Mask R-CNN, and Faster R-CNN, which are widely used for object detection tasks today.

I developed this project to explore how artificial intelligence can help automate everyday visual tasks across different fields. For example, it can be used in healthcare to monitor medical equipment or patient activity, in automotive applications for detecting vehicles and pedestrians, in retail for tracking products and customers, and even in security surveillance to identify suspicious objects or movements. The idea was to show how object detection can make systems smarter and more efficient in the real world.

The system follows a complete pipeline — starting from data collection and preprocessing, then model training and fine-tuning, and finally testing and real-time detection. I used transfer learning from pretrained models on large datasets like COCO to improve performance with less training data. The YOLO family of models worked best for this project because it offers an excellent balance between speed and accuracy, which is perfect for real-time use cases.

The repository includes Python scripts and Jupyter notebooks that explain each step of the process. The main script, main_proj.py, is used to run live detection through a webcam or on a set of images. The notebooks, such as Springboard.ipynb and Springboard YOLOv5n.ipynb, include experiments with different model architectures, training methods, and performance evaluations. All dependencies are listed in the requirements.txt file, so setting up the environment is as simple as running pip install -r requirements.txt. Once installed, you can launch the detection with a single command and watch objects being recognized in real time.

The project uses technologies like PyTorch, OpenCV, NumPy, and Matplotlib for model training, image processing, and visualization. On a decent system, the model runs at around 30 frames per second, drawing bounding boxes and labels for detected objects. The results were quite impressive — the model achieved strong precision and recall values, and it was able to generalize well to new images outside of the training set.

Looking ahead, I plan to extend this system by adding a web interface using Flask or Streamlit, deploying it on cloud platforms like AWS or Google Cloud, and optimizing it for edge devices such as Raspberry Pi. These additions will make it easier to deploy the model in real-world scenarios and make object detection more accessible to different kinds of users and industries.

Overall, the Object Recognition System has been a great learning experience for me — combining computer vision, deep learning, and real-time processing into one working project. It reflects how AI can bridge the gap between machines and human perception, helping us build smarter, faster, and more reliable systems that understand the world around them.
